## 🚀 Projetos em Destaque

### 🧠 [NODUS — Sistema de Gestão Terapêutica](https://github.com/cathsatile/NODUS-Projeto-Integrador-II)
> Projeto Integrador II (2026) · Colaborador ativo

Sistema web completo para gestão de sessões de terapia em consultórios e clínicas-escola, com foco em segurança de dados clínicos sensíveis.

- Arquitetura **offline-first** com Dexie.js (IndexedDB) para uso sem conexão estável
- **Criptografia client-side** com Crypto-js para proteção de dados de saúde mental
- Stack: **Angular 18+** (Signals, Standalone Components), **Capacitor** (Mobile-First), **TypeScript**, **SCSS**, **Java** (back-end)
- Autenticação OAuth implementada no repositório [`nodus-oauth`](https://github.com/Davi-KL/nodus-oauth)
