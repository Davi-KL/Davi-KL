- 🗄️ **SQL em larga escala** — consultas, manutenção e análise de dados em banco de dados hospitalar de grande volume
- 🌐 **Desenvolvimento web interno** — criação de páginas e dashboards para controle de dados e acesso de colaboradores na intranet da rede

- 🧪 **Testes de software** — desenvolvimento e execução de testes para garantia de qualidade do código
